# FunnyVisuals (Fabric, Minecraft 1.21.4)

Клиентский мод со смешными визуальными эффектами.

## Что умеет
- Радужный след за игроком (спринт добавляет искры)
- Конфетти-дождь вокруг игрока и залп конфетти
- Радужный HUD: волнистый заголовок, статус функций, FPS, пульсирующая рамка прицела
- Радужное небо и туман

## Управление (меняется в настройках управления, категория FunnyVisuals)
| Клавиша | Действие |
|---|---|
| J | след |
| K | HUD |
| L | небо и туман |
| H | конфетти-дождь |
| G | залп конфетти |

Команды: `/funny`, `/funny <trail|hud|sky|rain|burst>`, `/funny intensity <1-10>`.
Настройки сохраняются в `config/funnyvisuals.properties`.

## Сборка
Нужны JDK 21 и Gradle 8.12+ (или IntelliJ IDEA, она всё настроит сама).
```
gradle wrapper --gradle-version 8.12
./gradlew build
```
Готовый jar: `build/libs/funnyvisuals-1.0.0.jar`. Положите его в `mods/` вместе с Fabric API.
Для запуска из среды разработки: `./gradlew runClient`.

## Если игра падает при запуске
Небо и туман сделаны через два миксина (`ClientWorldMixin`, `BackgroundRendererMixin`).
Это единственная часть, зависящая от внутренних сигнатур Minecraft. Если что-то не совпало,
уберите их из `funnyvisuals.mixins.json`: остальной мод работает без них.
